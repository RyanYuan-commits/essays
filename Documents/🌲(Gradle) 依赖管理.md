## 1 Gradle 4.x

| 关键字               | 作用              | 编译时需要 | 运行时需要 | 传递性 | 典型用例                                        |
| ----------------- | --------------- | ----- | ----- | --- | ------------------------------------------- |
| **`compile`**     | 编译、打包和运行的主要依赖   | ✅     | ✅     | ✅   | 绝大多数常规依赖，例如 `Spring Boot`、`Apache Commons`。 |
| **`testCompile`** | 仅用于编译和运行测试代码    | ✅     | ✅     | ❌   | 测试框架，例如 `JUnit`、`Mockito`。                  |
| **`provided`**    | 仅用于编译，在运行时由外部提供 | ✅     | ❌     | ❌   | Java EE 应用中的 `servlet-api`，`JSP` API。       |
| **`runtime`**     | 仅在运行时需要，编译时不需要  | ✅     | ✅     | ✅   | JDBC 驱动，例如 `mysql-connector-java`。          |

## 2 Gradle 7.x

| 关键字                      | 作用              | 编译时需要 | 运行时需要 | 传递性？ | 典型用例                                         |
| ------------------------ | --------------- | ----- | ----- | ---- | -------------------------------------------- |
| **`implementation`**     | **内部实现**依赖      | ✅     | ✅     | ❌    | 绝大多数常规依赖，例如业务模块中的 JSON 库、数据库连接池。             |
| **`api`**                | **公共接口**依赖      | ✅     | ✅     | ✅    | 你的模块是一个库，且公共 API 中使用了另一个库的类型。                |
| **`testImplementation`** | 仅用于编译和运行测试代码    | ✅     | ✅     | ❌    | 测试框架，例如 `JUnit 5`、`Mockito`。                 |
| **`testCompileOnly`**    | 仅用于编译测试代码       | ✅     | ❌     | ❌    | 在测试中使用的注解处理器。                                |
| **`compileOnly`**        | 仅用于编译，在运行时由外部提供 | ✅     | ❌     | ❌    | Java EE 应用中的 `jakarta.servlet-api`，`lombok`。 |
| **`runtimeOnly`**        | 仅在运行时需要，编译时不需要  | ❌     | ✅     | ❌    | JDBC 驱动，例如 `mysql-connector-java`。           |
