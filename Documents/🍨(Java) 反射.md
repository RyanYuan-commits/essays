## 1 基本介绍

### 1.1 什么是反射?

Java 反射是一种机制, 它允许一个 Java 程序在 **运行时(runtime)** 动态的查询, 检查和操作类, 方法, 字段等内部信息, 而无需在编译时就确定这些元素的具体名称.
### 1.2 反射的应用场景

开发通用框架: 很多框架 (如 Spring) 是配置化的, 为了保证框架的通用性, 需要在运行时构造不同的对象, 调用不同方法;

动态代理机制: 在切面编程中, 需要拦截特定的方法, 而 Java Proxy 是基于反射实现的;

注解: 注解本身仅仅起到标记的作用, 它需要利用反射机制, 根据注解标记去调用注解解释器, 执行行为;

可拓展性功能: 可以通过 `Class.forName(...)` 来动态的加载类, 实现应用程序的可拓展.
### 1.3 反射的缺点

性能开销: 反射是一种动态解析, 无法执行 JVM 优化;

破坏封装性: 可忽略权限检查, 可能会破坏封装性;

内部依赖: 反射允许代码依赖非公开的, 内部实现的 API,  可能会随着平台升级带来意料之外的问题.
