## 1 移动语义

一个变量可以把它拥有的值转移给另一个变量, 称为所有权转移, 赋值语句, 函数调用, 函数返回都有可能导致所有权转移:

```rust
fn create() -> String {
    let s = String::from("Hello, world!");
    s // 所有权转移
}

fn consume(s: String) {
    println!("{}", s);
}

fn main() {
    let s = create(); // s 获得所有权
    consume(s); // 所有权转移到 consume 函数
    // println!("{}", s); // 这里会报错，因为 s 的所有权已经被转移
}
```

Rust 中所有权转移的重要特点是: 它是所有类型的**默认语义**.
