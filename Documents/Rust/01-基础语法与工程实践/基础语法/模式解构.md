## 1 简介

```rust
let tuple = (i_i32, false, 3f32);
let (head, center, tail) = tuple;
```

上面的代码是一个典型的 "模式解构", 第一个语句是 "构造", 将三个元素组合到一起形成一个 `tuple`, 而第二个越剧是将其拆解开来, 分成了三个不同的变量;

在 `let` 语句中, 赋值号左边的内容就是 Pattern, 而赋值号右边就是需要被 Destructure 的内容;

这个 Pattern 引入了三个变量, 分别绑定了这个 `tuple` 的三个成员.

Rust 中的模式解构的原则是: **构造和解构遵循类似的语法**, 怎么将一个数据结构组合起来, 就怎么把它拆解开来:

```rust
struct T1 (i32, char);

struct T2 {
    item1: T1,
    item2: bool,
}

fn main() {
    let x = T2 {
        item1: T1(0, 'A'),
        item2: true,
    };
    
    let T2 {
        item1: T1(value1, value2),
        item2: value3,
    } = x;
    println!("{} {} {}", value1, value2, value3);
}
```

首先构造了一个 T2 类型的变量 X, 内部又嵌套了其他的结构体, 而通过 Pattern Destructure, 可以一次性解构多个层级.

Rust 的模式解构不仅出现在 `let` 语句中, 还可以出现在 `match`, `if let`, `while let`, 函数调用, 闭包调用等场景中.

## 2 match

```rust
enum Direction {
    East, South, West, North
}

fn print(x: Direction) {
    match x {
        Direction::East => println!("East"),
        Direction::South => println!("South"),
        Direction::West => println!("West"),
        Direction::North => println!("North"),
    }
}

fn main() {
    let d = Direction::East;
    print(d);
}
```

当一个类型有多重取值可能的时候, 特别适合使用 match 表达式.

### 2.1 exhaustive

Rust 要求 match 需要对所有的情况做完整的, 无遗漏的匹配, default 分支使用 `_` 实现:

```rust
fn print(x: Direction) {
    match x {
        Direction::East => println!("East"),
        _ => println!("Other"),
    }
}
```

---

当多个项目存在依赖关系的时候, 在上游的一个库中对 `enum` 增加成员, 是一个破坏兼容性的改动, 很可能会导致下游的使用者 match 语句编译不通过, 为了解决这个问题, Rust 提供了一个叫做 `non_exhaustive` 的功能.

```rust
#[non_exhaustive] 
pub enum Error { 
	NotFound, 
	PermissionDenied, 
	ConnectionRefused, 
}
```

### 2.2 下划线

下划线还能用在模式匹配的各种地方, 表示匹配到了但是忽略它的值的情况:

```rust
struct P(f32, f32, f32); 

fn calc(arg: P) -> f32 { 
	// 匹配 tuple struct,但是忽略第二个成员的值 
	let P(x, _, y) = arg; x * x + y * y 
} 

fn main() { 
	let t = P(1.0, 2.0, 3.0);
	println!("{}", calc(t)); 
} 
```

对于上面的案例, 可以写的更简单一些, 因为函数本身就具备模式解构的能力:

```rust
struct P(f32, f32, f32); 

fn calc(P(x, _, y): P) -> f32 { 
	// 匹配 tuple struct,但是忽略第二个成员的值 
	x * x + y * y 
} 

fn main() { 
	let t = P(1.0, 2.0, 3.0);
	println!("{}", calc(t)); 
} 
```

### 2.3 match 也是表达式

match 语法结构同样可以作为表达式的一部分:

```rust
enum HttpError {
    BadRequest,
    Unauthorized,
    Forbidden,
    NotFound,
    InternalServerError,
}

fn to_status_code(error: HttpError) -> u16 {
    match error {
        HttpError::BadRequest => 400,
        HttpError::Unauthorized => 401,
        HttpError::Forbidden => 403,
        HttpError::NotFound => 404,
        HttpError::InternalServerError => 500,
    }
}

fn main() {
    let error = HttpError::NotFound;
    let status_code = to_status_code(error);
    println!("Status code: {}", status_code);
}
```

match 可以使用运算符 `|` 来匹配多个条件, 比如:

```rust
fn category(x: i32) {
    match x {
        -1 | 1 => println!("one"),
        0 => println!("zero"),
        2..=10 => println!("small"),
        _ => println!("other"),
    }
}
```

### 2.4 Guards

可以使用 if 作为 "匹配看守" (match guards), 可以实现当匹配成功且符合 if 条件, 才执行后面的语句:

```rust
fn main() {
    enum OptionalInt {
        Value(i32),
        None,
    }

    let x = OptionalInt::Value(5);

    match x {
        OptionalInt::Value(v) if v > 10 => println!("The value is: {}", v),
        OptionalInt::None => println!("No value present"),
        _ => println!("Value is 10 or less"),
    }
}
```
