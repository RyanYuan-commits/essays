Rust 的字符串涉及两种类型, 一种是 `&str`, 另一种是 `String`.

## 1 &str

str 是 Rust 的内置类型, 而 `&str` 是对这个内置类型的借用, 是一个胖指针;

Rust 的字符串是使用 UTF-8 编码的, 而内置的 Char 存储的是 Unicode 编码, 所以 Rust 的字符串不能视为 char 类型的数组;

这样设计的缺点是不能支持 O(1) 时间复杂度的索引操作, 在 Rust 中, 如果想要找到一个字符串内部的第 N 个字符, 需要这样操作:

```rust
s.chars().nth(n);
```

因为 UTF-8 是变长字符串, 所以这个操作的时间复杂度是 O(n).

## 2 String

`String` 类型有管理内存空间的权利, 而 `&str` 是对一块字符串区间的借用, 它对指向的内存空间没有所有权, 哪怕 `&mut str` 也一样;

这种所有权差异决定了它们的行为模式. `String` 因拥有底层数据, 能够自由地增长、收缩或修改其内容, 这使其成为处理动态字符串的理想选择. 

```rust
fn main() {
    let mut s = String::from("Hello");
    s.push(' ');
    s.push_str("World.");
    println!("{}", s);
}
```

相反, `&str` 作为对现有数据的借用, 无法改变其所指向内存区域的长度, 即使是可变的 `&mut str` 也仅限于修改其内容而非大小.

因此, 在实践中, `String` 常用于需要构建、拼接或从外部来源(如用户输入或文件)获取字符串数据的情景. 而 `&str` 则更多地用作函数参数, 接受任何字符串切片(包括 `String` 的切片), 或表示编译时已知的字符串字面量, 从而避免不必要的内存分配和数据复制, 提高效率.
