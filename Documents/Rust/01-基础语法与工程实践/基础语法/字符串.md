Rust 的字符串涉及两种类型, 一种是 `&str`, 另一种是 `String`.

## 1 &str

str 是 Rust 的内置类型, 而 `&str` 是对这个内置类型的借用, 是一个胖指针;

Rust 的字符串是使用 UTF-8 编码的, 而内置的 Char 存储的是 Unicode 编码, 所以 Rust 的字符串不能视为 char 类型的数组;

这样设计的缺点是不能支持 O(1) 时间复杂度的索引操作, 在 Rust 中, 如果想要找到一个字符串内部的第 N 个字符, 需要这样操作:

```rust
s.chars().nth(n);
```

因为 UTF-8 是变长字符串, 所以这个操作的时间复杂度是 O(n).

使用 UTF-8 的好处: https://utf8everywhere.org/zh-cn
