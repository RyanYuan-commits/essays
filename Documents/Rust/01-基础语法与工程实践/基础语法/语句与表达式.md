## 1 语句

在 Rust 程序中, 表达式和语句是完成流程控制, 计算求值的重要工具;

表达式可以是语句的一部分, 反过来, 语句也可以是表达式的一部分; 语句不产生值, 它的类型永远是 `()`; 

如果把表达式加上分号, 那么它就变成了一个语句, 而如果把语句放到语句块中包裹起来, 那么它就可以被当成表达式使用:

```rust
// 表达式 'x + 5' 后面没有分号，因此它返回 x+5 的值。
return x + 5

// 表达式 'x + 5' 后面有分号，它变为语句，返回 ()。
return { x + 5; } // 错误，函数期望返回 i32，但实际返回了 ()
```

## 2 表达式

在 Rust Reference 教程中有这样一句话: Rust is primarily an expression language; Rust 基本上就是一个表达式语言;

### 2.1 运算表达式

算数运算符: `+ - *, / %`

比较运算符: == != < > <= >=

位运算符:

| **运算符** | **作用**         |
| ------- | -------------- |
| `!`     | 按位取反(注意不是 `~`) |
| `&`     | 按位与            |
| \|      | 按位或            |
| `^`     | 按位异或           |
| `<<`    | 左移             |
| `>>`    | 右移             |

```rust
fn main() {
    let num1: u8 = 0b_1010_1010;
    let num2: u8 = 0b_1111_0000;

    println!("{:08b}", !num1); // 01010101
    println!("{:08b}", num1 & num2); // 10100000
    println!("{:08b}", num1 | num2); // 11111010
    println!("{:08b}", num1 ^ num2); // 01011010
    println!("{:08b}", num1 << 2); // 10101000
    println!("{:08b}", num1 >> 2); // 00101010
}
```

### 2.2 赋值表达式

Rust 不允许连续赋值, 赋值表达式的值为 `()`:

```rust
fn main() {
    let x = 1;
    let z = _ = x;
    println!("{:?}", z); // ()
}
```

Rust 支持组合表达式, 如 `+= -= /=` 等.

### 2.3 语句块表达式

在 Rust 中, 语句块也可以是表达式的一部分, 如果带分号意味着这是一条语句, 如果不带分号, 类型就是表达式的类型

```rust
let x: i32 = { 
	// 可以使用语句块的返回值;
	// Rust 按顺序指定语句块内的语句, 并将最后一个表达式类型返回.
	println!("Hello");
	100
};
```

## 3 控制语句

### 3.1 if-else

`if-else` 表达式根据条件执行不同的代码分支. Rust 中的 `if` 是一个表达式, 这意味着它可以返回值.

```rust
fn main() {
    let number = 3;

    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }
}
```

因为 `if` 是一个表达式, 我们可以 `let` 语句中使用它来将返回值赋给一个变量.

```rust
fn main() {
    let condition = true;
    let number = if condition { 5 } else { 6 };

    println!("The value of number is: {}", number);
}
```

需要注意的是, `if` 和 `else` 代码块中的返回值类型必须相同.

### 3.2 loop

`loop` 关键字告诉 Rust 一遍又一遍地执行一块代码, 直到你明确告诉它停止.

可以使用 `break` 关键字来退出循环. `break` 还可以从循环中返回值.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("The result is {}", result);
}
```

### 3.3 while

`while` 循环在每次循环开始时判断条件是否为 `true`. 如果条件为 `true`, 则执行循环体; 否则, 退出循环.

```rust
fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }

    println!("LIFTOFF!!!");
}
```

### 3.4 for

`for` 循环用于遍历一个集合中的每个元素, 例如数组或范围 (range).

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for element in a.iter() {
        println!("the value is: {}", element);
    }
}
```

也可以使用范围来指定循环次数:

```rust
fn main() {
    for number in (1..4).rev() { // .rev 方法可以反转范围
        println!("{}!", number);
    }
    println!("LIFTOFF!!!");
}
```
