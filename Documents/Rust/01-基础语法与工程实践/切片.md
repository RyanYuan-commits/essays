## 1 什么是切片

在 Rust 中, 切片是对一个集合 (如数组, `Vec` 或字符串) 中连续部分的引用, **它本身不拥有数据的所有权**.

切片的本质是一个胖指针(Fat Pointer), 它包含两个信息:

- **指向数据的指针**: 指向数据开始的内存地址;
- **长度**: 切片中的元素个数.

## 2 数组切片

通过 `[start_index...end_index]` 来创建切片, 范围是 **左闭右开**:

```rust
fn main() {
    let arr: [i32; 5] = [1, 2, 3, 4, 5];

    // 切片：从索引 1 开始，到索引 4 结束（不包含 4）。即 [2, 3, 4]
    let slice_mid: &[i32] = &arr[1..4]; 
    println!("{:?}", slice_mid); // 输出: [2, 3, 4]

    // 简写 1：省略起始索引，默认从 0 开始。即 [1, 2, 3]
    let slice_head: &[i32] = &arr[..3];
    
    // 简写 2：省略结束索引，默认到数组末尾。即 [3, 4, 5]
    let slice_tail: &[i32] = &arr[2..];
    
    // 简写 3：省略起始和结束，即整个数组的切片。
    let slice_all: &[i32] = &arr[..]; 
}
```

数组类型包含长度信息和类型信息, 必须两者完全相同才是同种类型的数组, 而数组切片的类型是 `&[T]`, 不包含长度信息, 在一些场景中比数组更灵活.

## 3 字符串切片

字符串切片是对 `String` 或静态字符串字面量中 UTF-8 编码的字节序列的引用.

### 3.1 两种字符串类型

`String` 类似 Java 的 `StringBuilder` , 数据存储在堆上, 可变, 拥有所有权;

`&str` 是字符串切片, 是 `String` 的视图, 不可变, 不用有所有权, 字符串字面量(例如 "hello"), 本身就是 `&str` 类型.

```rust
let s1: &str = "Hello, world!"; // 静态字符串字面量，类型为 &str
let s2: String = String::from("Rustacean");

// 从 String 创建切片（引用）
let slice_of_s2: &str = &s2[0..4]; // "Rust"
```

### 3.2 UTF-8 安全性

Rust 的字符串切片操作是 UTF-8 安全的, 切片操作必须在有效的 UTF-8 字符编辑进行.

```rust
let s = String::from("你好"); // 6个字节，每个汉字占 3 个字节
// let slice = &s[0..1]; // 运行时会 panic，因为 1 不是字符边界！
let slice = &s[0..3]; // 正确，切出“你”字
```

## 4 切片与所有权及借用

当你有一个数组的不可变引用 `&arr` 时, 可以创建不可变切片 `&arr[..]`;

而如果你有一个数组的可变引用 `&mut arr`, 你可以创建可变的切片 `&mut arr[..]`, 而当存在可变切片的时候, 不能同时存在任何其他的引用(无论是可变还是不可变的).

```rust
fn main() {
    let mut arr: [i32; 3] = [1, 2, 3];
    let mut_slice: &mut [i32] = &mut arr[1..];
    mut_slice[0] = 10;
    println!("{:?}", arr); // Output: [1, 10, 3]
}
```
