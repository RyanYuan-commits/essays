## 1 javap 核心使用方式

```bash
javap [OPTIONS] [CLASS_NAME]
```

常用的选项有:

- 无选项: 仅展示公共的字段和方法签名;
- `-c` 反汇编, 显示每个方法对应的 Java 字节码指令, 用于分析代码逻辑;
- `-v` 详细模式, 输出包括字节码, 局部变量表, 异常表, 行号等所有的详细信息;
- `-s` 输出内部类型签名, 用于检查泛型和复杂类型;
- `-l` 显示行号和本地变量表, 常与 `-c` 和 `-v` 一起使用;
- `-p` 显示所有的字段和方法, 包括私有的.
