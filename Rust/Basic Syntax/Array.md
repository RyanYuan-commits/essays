## 1 基本介绍

数组是一个容器, 它在一块连续空间内存中, 存储了一系列**相同类型**的数据;

数组中元素的占用空间大小和可容纳元素的个数必须是在编译期确定的, 在执行阶段不可变;

```rust
fn main() {
    let arr: [i32; 5] = [1, 2, 3, 4, 5];
    print!("{:?}", arr);
}
```

在 Rust 中, 对于两个数组类型, 只有 **元素类型和元素个数** 都完全相同, 这两个数组才是同类型的, 才能相互赋值:

```rust
fn main() {
    let mut x: [i32; 5] = [1, 2, 3, 4, 5];
    let y: [i32; 5] = [6, 7, 8, 9, 10];
    x = y;
    print!("{:?}", x); // Output: [6, 7, 8, 9, 10]
}
```

数组和指针之间不能隐式转化, 如果把数组传递给一个函数, 这个数字并不会退化为指针, 而是会将这个数组完整复制进函数, 函数体内对数组的改动不会影响到外面的数组;

访问数组元素:

```rust
fn main() {
    let x: [i32; 5] = [1, 2, 3, 4, 5];
    let sum = x[0] + x[1];
    println!("{:?}", sum); // Output: 3
}
```

## 2 内置方法

在 Rust 中, 我们可以直接实现数组的比较操作. 只要它包含的元素是可比较的, 这种比较是逐元素进行的, 遵循字典序的规则. 

它会从第一个元素开始, 依次比较对应位置的元素. 一旦发现两个不相等的元素, 比较的结果便会立即确定, 无需继续检查后续元素.

如果所有对应位置的元素都相等, 但两个数组的长度不同, 那么较短的数组将被视为“小于”较长的数组. 

这种强大的比较能力得益于 Rust 为所有包含可比较元素的数组自动实现的 [[Trait#8.2 PartialOrd/Ord & PartialEq/Eq|PartialEq 和 Eq]] trait.

```rust
fn main() {
    let x: [i32; 3] = [1, 2, 3];
    let y: [i32; 3] = [4, 5, 6];
    println!("{:?}", x > y); // Output: false
}
```

我们也可以对数组执行遍历操作:

```rust
fn main() {
    let arr = [0; 5];
    for x in arr {
        println!("{}", x);
    }
}
```

## 2 多维数组

```rust
fn main() {
    let arr: [[i32; 3]; 2] = [[1, 2, 3], [4, 5, 6]];
    for sub_arr in &arr {
        for &item in sub_arr {
            print!("{} ", item);
        }
        println!();
    }
}
```

## 4 DST 与胖指针

数组切片是一个指向数组的指针, 而它相比指针有多了一些东西, 也就是长度信息, 这种指针被称为胖指针;

与这个概念相对应的概念是 "动态大小类型" (Dynamic Sized Type, DST), 指的是大小在编译阶段无法确定占用空间大小的类型, 指向 DST 的指针一般是胖指针;

比如, 对于不定长数组类型 `[T]`, 有对应的胖指针 `&[T]`, 对于不定长字符串 `str`, 有对应的胖指针 `&str`.
